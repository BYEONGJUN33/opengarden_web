# OpenGarden 프로젝트 구조 정리 v2

> 원칙: **프로젝트 1개 · 페이지 2개 · 함수 2개 · 데이터 원본 1개(에어테이블)**
> 이 문서가 지금부터의 기준. 이전 문서(인수인계 v1의 5페이지 구조)는 이 문서로 대체.

---

## 1. 폴더 구조 (최종형)

```
opengarden/                     ← 프로젝트 루트 (호스팅 어디든 동일)
├─ public/                      ← 사용자가 보는 정적 파일
│  ├─ index.html                홈 원페이지 (소개·서비스·FAQ 전부 흡수)
│  ├─ catalog.html              카탈로그 + 견적 플로우
│  └─ assets/
│     ├─ logo.svg               로고
│     ├─ og.jpg                 카톡 공유 미리보기 이미지 (1200×630)
│     └─ img/                   사진 (히어로·사례·서비스 블록)
├─ api/                         ← 서버리스 함수 (백엔드 전부)
│  ├─ catalog.js                GET  /api/catalog  · 에어테이블 읽기
│  └─ quote.js                  POST /api/quote    · 견적 기록 + 요청번호
├─ package.json
└─ README.md                    셋업·배포 순서
```

## 3. catalog.html — 내부 구조

```
헤더 (공통 내비)
페이지 헤드 (제목 + 안내 한 줄)
툴바 [sticky] ─ 검색 / 내한성 select / 공급구분 select / 카테고리 칩
카드 그리드 ─ 사진 · 국명 · 학명 · 규격/존/카테고리 태그 · [견적에 담기]
하단 견적 바 [fixed] ─ "N종 선택됨 · 견적 요청하기"
견적 모달 ─ 품목 수량 조절 · 성함/요청사항 · [목록 복사하고 카톡 열기]
토스트 알림
```

**상태(데이터) 3개**: `PLANTS`(품종 목록) · `cart`(담은 품목) · 필터 상태
**연결 지점 2개**:
- `init()` → `GET /api/catalog` (실패 시 샘플 데이터로 동작 → 로컬에서도 확인 가능)
- `sendQuote()` → `POST /api/quote` 기록 + 클립보드 복사 + `KAKAO_URL` 열기

## 4. 연결 매핑 (사이트 ↔ 함수 ↔ 에어테이블)

| 사이트 위치 | 함수 | 에어테이블 |
| --- | --- | --- |
| 카탈로그 카드 그리드 | GET /api/catalog | Master DB의 View 2개 (즉시 출하 / 사전 예약) |
| 견적 모달 → 보내기 | POST /api/quote | 견적요청 테이블 (신규 생성 필요) |
| 카드 이미지 | (catalog 경유) | `이미지_URL` 필드 — 고정 URL만 사용 |
| 가격 | 없음 | 단가 필드는 함수가 차단, 사이트 미노출 |
