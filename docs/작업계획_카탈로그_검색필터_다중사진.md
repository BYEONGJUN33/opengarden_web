## 1단계 — 다중 사진 (DB 변경 없음)

### 1-1. API (`api/catalog.js`)
- 첨부 배열 전체를 `images: [{ full, thumb }]` 로 반환
- 기존 `image` 키는 **그대로 유지** (첫 장) — 하위 호환, 롤백 안전
- 썸네일은 지금처럼 `thumbnails.large` 우선, 없으면 원본

### 1-2. 카드 (그리드)
- 대표 사진 1장 유지 (그리드가 흔들리면 안 됨)
- 2장 이상일 때만 우측 하단에 `1/3` 형태의 장수 배지

### 1-3. 상세 모달 — 갤러리
- 메인 사진 + 하단 썸네일 스트립
- 조작: 썸네일 클릭 / 좌우 화살표 / 키보드 ←→ / 모바일 스와이프
- 사진 1장이면 스트립·화살표 **미표시** (판매 라인업 241건이 여기 해당)
- 접근성: 화살표에 `aria-label`, 스트립은 `role="tablist"`
- `prefers-reduced-motion` 존중 (기존 규칙과 동일)

### 1-4. 성능
- 첫 장만 즉시 로드, 나머지는 모달 열릴 때 지연 로드
- 첨부 URL은 수 시간 후 만료되나 캐시가 10분이라 문제 없음 (기존과 동일 조건)

**예상 작업량**: 반나절 · 위험도 낮음 · 롤백 쉬움

## 2단계 — 검색·필터 (DB 변경 있음 ⚠️)

### 2-1. 이미 있는 것
현재 카탈로그에 **검색창·내한성·공급구분·카테고리 칩**이 이미 동작 중이며 AND 결합됨.
Plantipp 대비 없는 것은 **색상 필터**와 **알파벳 색인** 둘뿐.

### 2-2. 색상 필터 — DB 선행 작업 필요
Plantipp 색상 목록: white / blue / purple / lilac / pink / orange / red / cream / yellow / green

**필요 작업 (에어테이블에서 사람이 해야 함)**
1. 두 테이블에 `색상` 필드 신설 — 타입은 **`multipleSelects`** 권장
   (튤립·수국은 복색이 흔해 단일 선택이면 표현 불가)
2. 선택지는 Plantipp 10색을 한글로 고정: 흰색·파랑·보라·라일락·분홍·주황·빨강·크림·노랑·초록
3. **297건 전부 값 입력** — 이게 실제 비용. 사진 보고 판단해야 하므로 자동화 불가

> 데이터가 비어 있으면 필터를 달아도 결과가 0건이라, **입력이 끝난 뒤 배포**하는 게 맞습니다.
> 부분 입력 상태로 내보내면 "색 골랐더니 아무것도 없다"가 됩니다.

**코드 쪽**: 필드ID 화이트리스트에 추가 → `colors: []` 반환 → 드롭다운 + AND 필터. 반나절.

### 2-3. 알파벳 색인 — 기준 결정 필요
Plantipp은 라틴 학명 기준 A–Z.

| 안 | 기준 | 장점 | 단점 |
|---|---|---|---|
| **A** | 국명 ㄱ~ㅎ | 한국 고객에게 자연스러움 | 레퍼런스와 다름 |
| **B** | 학명 A~Z | 레퍼런스와 동일, 조경 실무자에게 익숙 | 일반 고객엔 낯섦 |
| **C** | 둘 다 토글 | 양쪽 커버 | UI 복잡, 모바일 부담 |

초성 추출은 유니코드 계산으로 처리 가능 (라이브러리 불필요).
**해당 글자가 없으면 버튼 비활성** 처리 — 눌렀는데 빈 화면이 뜨면 안 됨.

### 2-4. 페이지네이션 — 지금은 불필요, 곧 필요
현재 297건 전량 렌더 중이며 체감 문제 없음.
다만 대표님이 말씀하신 **1,500종**이 들어오면 모바일에서 무너집니다.
→ 이번엔 손대지 않되, **1단계 작업 시 렌더 구조만 페이지네이션 삽입이 쉽도록 정리**해 둡니다.

## 순서 제안

```
1단계 다중 사진 (DB 무관, 바로 착수)
   ↓
2단계-A 알파벳 색인 (DB 무관, 기준만 정하면 됨)
   ↓  ← 병행: 에어테이블 색상 입력 (297건, 사람 작업)
2단계-B 색상 필터 (입력 완료 후 배포)
```

색상 입력이 병목이라, 그동안 코드 쪽은 앞의 두 개를 끝내 둡니다.

## 결정이 필요한 것

1. **색상 필드 타입** — `multipleSelects`(복색 가능) vs `singleSelect`(단순)
2. **알파벳 색인 기준** — 국명 ㄱ~ㅎ / 학명 A~Z / 둘 다
3. **색상 297건 입력** — 누가, 언제. 이게 2단계-B 일정을 결정
4. 판매 라인업 241건은 사진이 1장뿐인데, **추가 촬영·수집 계획이 있는지**
   (없다면 갤러리 UI는 당분간 국내 56건에서만 보입니다)
