# 에어테이블 토큰 발급 — 대표님용

> 웹사이트 카탈로그가 에어테이블 데이터를 읽어오는 **열쇠**입니다.
> 담당자 계정으로 만든 열쇠는 퇴사하면 못 쓰게 되므로, **대표님 계정으로 새로 만듭니다.**
> 10분이면 끝납니다.

---

## 시작 전 확인

대표님 에어테이블 계정에서 **OpenGarden** 베이스가 보여야 합니다.
안 보이면 담당자에게 공유를 먼저 요청하세요.

---

## 1. 토큰 만들기 화면 열기

주소창에 입력합니다.

```
airtable.com/create/tokens
```

→ **Create token** 버튼 클릭

---

## 2. 이름 입력

**Name** 칸에 알아보기 쉬운 이름을 넣습니다.

```
오픈가든 웹사이트
```

나중에 "이 열쇠가 어디에 쓰이는지" 구분하는 용도라 아무 이름이나 괜찮습니다.

---

## 3. 권한 선택 (Scopes)

**+ Add a scope** 를 눌러 아래 **7개를 전부** 추가합니다.
하나씩 눌러 추가해야 해서 조금 번거롭지만, 한 번만 하면 됩니다.

```
data.records:read
data.records:write
schema.bases:read
schema.bases:write
data.recordComments:read
data.recordComments:write
webhook:manage
```

| 권한 | 왜 필요한가 |
|---|---|
| `data.records:read` | **카탈로그에 품종이 표시됩니다.** 없으면 사이트가 빈 화면이 됩니다 |
| `data.records:write` | 고객 견적 요청이 에어테이블에 기록됩니다. 농장 재고조정앱도 이걸 씁니다 |
| `schema.bases:read` · `schema.bases:write` | 테이블·필드·선택지를 수정할 수 있게 합니다. 지금 미뤄둔 품종명 오타와 중복 정리를 자동으로 처리하려면 필요합니다 |
| `data.recordComments:*` | 레코드 댓글. 당장은 안 쓰지만 나중에 쓸 수 있게 |
| `webhook:manage` | 자동화 연동. 당장은 안 쓰지만 나중에 쓸 수 있게 |

> 뒤 3개(`recordComments`, `webhook`)는 지금 당장 필요하진 않습니다.
> 나중에 또 발급받는 번거로움을 피하려고 미리 넣어두는 것입니다.

---

## 4. 접근 범위 선택 (Access)

**+ Add a base** 를 누르고 **OpenGarden** 을 선택합니다.

> ⚠ 목록에 **Campaign Tracker** 라는 다른 베이스도 보일 수 있습니다. **선택하지 마세요.**
> 웹사이트와 무관하고, 열쇠가 닿는 범위는 좁을수록 안전합니다.

---

## 5. 만들기

맨 아래 **Create token** 을 누릅니다.

### ⚠ 여기가 제일 중요합니다

**토큰 값은 이 화면에서 딱 한 번만 보입니다. 창을 닫으면 다시 볼 수 없습니다.**

화면에 `pat...` 로 시작하는 긴 문자열이 뜨면:

1. **Copy** 를 눌러 복사
2. **창을 닫기 전에** 바로 Vercel에 붙여넣기 (아래 6번)

놓치셨다면 그 토큰은 버리고 **Regenerate token** 으로 새로 만들면 됩니다. 다시 하셔도 괜찮습니다.

---

## 6. Vercel에 넣기

1. vercel.com → 오픈가든 프로젝트 → **Settings** → **Environment Variables**
2. **Add Environment Variable** 클릭
3. 입력:
   - Name: `AIRTABLE_TOKEN`
   - Value: 방금 복사한 `pat...` 값
   - 적용 환경: **Production** 과 **Preview** 둘 다 체크
4. **Save**
5. **Deployments** 탭 → 맨 위 배포의 **···** → **Redeploy**

> 저장만 하면 반영되지 않습니다. **Redeploy를 꼭 눌러주세요.**

---

## 7. 확인

2분쯤 기다린 뒤 브라우저에서 엽니다.

```
open-garden.co.kr/catalog.html
```

**품종 목록이 뜨면 성공입니다.**

| 증상 | 원인 |
|---|---|
| 목록이 안 뜬다 | 토큰 값이 잘못 붙여졌거나, Redeploy를 안 했거나, 베이스 선택이 빠짐 |
| "불러오지 못했습니다" | 권한(Scopes)에 `data.records:read`가 빠짐 |

안 되면 담당자 퇴사 전에 알려주세요. 옛 토큰이 살아 있는 동안은 되돌릴 수 있습니다.

---

## 다 끝난 뒤

옛 토큰(담당자 계정의 것)은 더 이상 필요 없습니다.
담당자가 자기 계정에서 삭제하면 됩니다. **새 토큰으로 사이트가 정상 동작하는 걸 확인한 뒤에** 지우세요.
