# 오픈가든 웹사이트 — 인수인계 체크리스트

> 담당자 퇴사에 따라 모든 계정·소유권을 대표 계정으로 넘기는 절차.
> **순서를 지켜야 사이트가 멈추지 않습니다.** 2026-10-25 작성.

---

## 왜 순서가 중요한가

사이트는 담당자 개인 계정으로 발급한 **토큰 14개**에 의존합니다.
담당자 계정이 사라지면 토큰이 먼저 죽고, 그 즉시 아래 기능이 멈춥니다.

| 토큰이 죽으면 | 멈추는 기능 |
|---|---|
| `AIRTABLE_TOKEN` | **카탈로그 전체** · 견적 접수 · 재고조정앱 |
| `SOLAPI_*` (5개) | 견적 접수 **알림톡 발송** |

그래서 **소유권을 넘기기 전에, 대표 계정으로 발급한 새 토큰으로 먼저 갈아끼웁니다.**
이렇게 하면 담당자 계정을 지워도 사이트는 멀쩡합니다.

```
1단계  대표 계정 개설        →  2단계  새 토큰으로 교체(사이트는 이미 대표 자원으로 동작)
   →  3단계  소유권 이전     →  4단계  담당자 계정 제거
```

---

## 1단계 · 대표 계정 개설 (대표님이 하실 일)

| 서비스 | 주소 | 비고 |
|---|---|---|
| GitHub | github.com | 저장소 이전 받을 계정 |
| Vercel | vercel.com | **GitHub 계정으로 로그인** 권장 |
| 에어테이블 | airtable.com | |
| 솔라피 | solapi.com | 알림톡 발송. 사업자 정보 필요 |

---

## 2단계 · 토큰 교체 (담당자 재직 중에 끝내야 함) ⚠ 가장 중요

### 2-1. 에어테이블

1. 담당자가 대표님을 **베이스 소유자(Owner)** 로 초대 (베이스 우상단 Share)
2. **대표님 계정에서** 개인 액세스 토큰 발급
   - airtable.com/create/tokens → Create new token
   - Scopes: `data.records:read`, `data.records:write`
   - Access: **OpenGarden 베이스만** 선택 (전체 워크스페이스 ✗)
3. Vercel → 프로젝트 → Settings → Environment Variables → `AIRTABLE_TOKEN` 값을 새 토큰으로 교체
4. **Redeploy** 후 카탈로그가 뜨는지 확인

> 기존 토큰은 개발 중 대화에 노출된 이력이 있어, 어차피 정식 오픈 전 재발급 대상이었습니다.
> 이번에 교체하면 그 건도 함께 해결됩니다.

### 2-2. 솔라피

1. 대표님 계정에서 API 키 발급 (콘솔 → 개발/연동 → API Key)
2. 카카오 알림톡 **채널·템플릿을 대표님 계정으로 등록** (채널 연동 → 템플릿 심사)
3. Vercel 환경변수 5개 교체: `SOLAPI_API_KEY` `SOLAPI_API_SECRET` `SOLAPI_PFID` `SOLAPI_SENDER` `SOLAPI_TEMPLATE_ID`
4. 카탈로그에서 견적을 한 건 넣어 알림톡이 오는지 확인

> 템플릿 심사에 영업일 기준 1~3일 걸립니다. **가장 먼저 시작하세요.**

### 2-3. 나머지 환경변수

아래는 토큰이 아니라 식별자라 그대로 두면 됩니다.

```
AIRTABLE_BASE_ID  AIRTABLE_TABLE_DOMESTIC  AIRTABLE_TABLE_IMPORT
AIRTABLE_QUOTE_TABLE  AIRTABLE_STOCK_TABLE  AIRTABLE_WORKER_TABLE
AIRTABLE_GROUP_TABLE  STOCK_FARMS
```

**교체 전에 Vercel 환경변수 전체를 복사해 따로 보관해두세요.** 되돌릴 때 필요합니다.

## 3단계 · 소유권 이전

### 3-1. Vercel 프로젝트

Vercel 공식 절차로 **무중단 이전**이 됩니다.

> 조건: 이전하는 쪽은 **Owner**, 받는 쪽 팀의 **멤버**여야 합니다.

**방법 A — 프로젝트 이전 (권장, 단 대표님 Pro 팀 필요)**
1. 대표님이 Vercel **Team** 생성 후 담당자를 멤버로 초대
2. 담당자: 프로젝트 → Settings → General → 맨 아래 **Transfer Project** → 대표님 팀 선택
3. 넘어가는 것: 배포 이력 · **환경변수** · **도메인** · Git 연동 · 보안 설정 · 크론
4. **안 넘어가는 것: 통합(Integrations)** → 이전 후 다시 연결해야 합니다
5. 받는 팀에 **결제수단이 등록돼 있어야** 합니다

**방법 B — 계정 자체를 넘기기 (무료, Hobby일 때)**
Vercel 무료(Hobby) 플랜은 팀원 초대가 안 돼 방법 A를 쓸 수 없습니다.
이때는 담당자 Vercel 계정의 **이메일을 대표님 이메일로 변경**해 계정째 넘깁니다.
(Settings → General → Email). 로그인 수단도 함께 바꿔야 합니다.

> Vercel 무료 플랜은 **비상업적·개인 용도만** 허용됩니다. 상업 사이트이므로
> 어느 쪽이든 Pro 전환을 검토하시는 게 안전합니다.

### 3-2. GitHub 저장소

1. 저장소 → Settings → General → 맨 아래 **Transfer ownership** → 대표님 계정
2. 이전 후 **Vercel 연동이 끊길 수 있습니다.** 반드시 확인:
   - Vercel → 프로젝트 → Settings → Git → 저장소가 올바로 연결돼 있는지
   - 끊겼으면 **Connect Git Repository**로 다시 연결
   - 대표님 계정에 **Vercel GitHub App 설치**가 필요할 수 있습니다
3. 아무 문구나 한 줄 고쳐 커밋 → 1~2분 뒤 사이트에 반영되는지로 확인

> **Vercel 이전을 먼저, GitHub 이전을 나중에** 하시면 연동 복구가 한 번으로 끝납니다.

### 3-3. 에어테이블

- 베이스가 속한 **워크스페이스 소유자**를 대표님으로 변경
  (워크스페이스 설정 → Members → 대표님을 Owner로 → 담당자 제거)
- 베이스만 공유하면 담당자 계정 삭제 시 워크스페이스째 사라질 수 있습니다

### 3-4. 도메인 (open-garden.co.kr)

현재 A 레코드가 Vercel(`216.198.79.1`)을 가리키고 있습니다.
도메인 자체는 **국내 등록기관(가비아·후이즈·카페24 등)** 에 있습니다.

1. 어느 기관에 등록돼 있는지 확인 (whois.kr 조회)
2. 해당 기관에서 **등록인(소유자) 정보 변경** 신청
   - 보통 사업자등록증·대표자 신분증 등 서류가 필요합니다
   - 기관마다 양식이 달라 고객센터 문의가 빠릅니다
3. 결제수단·자동갱신을 대표님 것으로 변경 **(갱신 실패 시 도메인이 만료됩니다)**

> DNS 설정은 건드리지 마세요. 소유자만 바뀌면 사이트는 그대로 동작합니다.

### 3-5. 카카오톡 채널

- 채널명: `pf.kakao.com/_lGfxhX`
- 카카오 비즈니스 채널 관리자센터 → 관리자 권한에 대표님 추가 → **마스터 권한 양도** → 담당자 제거

### 3-6. 네이버 서치어드바이저

사이트 소유확인이 담당자 계정에 묶여 있습니다.

```html
src/index.html
<meta name="naver-site-verification" content="a298...43e9" />
```

1. 대표님 계정으로 searchadvisor.naver.com에서 사이트 등록
2. 발급된 새 인증 코드로 위 줄의 `content` 값을 교체 후 커밋
3. 네이버에서 소유확인 완료
4. 담당자 계정에서는 사이트 삭제

**3단계까지 전부 끝나고, 아래 검증을 통과한 뒤에** 진행하세요.

## 인계 완료 검증 (이 5가지가 되면 끝)

| # | 확인 방법 | 정상 |
|---|---|---|
| 1 | open-garden.co.kr/catalog.html 열기 | 품종 목록이 뜬다 (에어테이블 토큰 정상) |
| 2 | 카탈로그에서 견적 한 건 접수 | 요청번호가 뜨고 **알림톡이 온다** (솔라피 정상) |
| 3 | 에어테이블 견적요청 테이블 확인 | 방금 접수건이 기록돼 있다 |
| 4 | GitHub에서 문구 한 줄 수정·커밋 | 1~2분 뒤 사이트에 반영된다 (Git 연동 정상) |
| 5 | Vercel 대시보드 | 대표님 계정에서 프로젝트가 보인다 |

하나라도 실패하면 **담당자 계정을 지우기 전에** 해결하세요.
계정을 지운 뒤에는 되돌릴 방법이 없습니다.
