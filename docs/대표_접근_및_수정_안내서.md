# 오픈가든 웹사이트 — 대표님 수정 안내서

> 코드를 몰라도 문구·사진·카탈로그는 직접 고치실 수 있습니다.
> 이 문서 하나만 보시면 됩니다. 2026-10-21 기준.

---

## 0. 어디를 고치면 어디가 바뀌나

| 바꾸고 싶은 것 | 고치는 곳 | 반영 시간 |
|---|---|---|
| 카탈로그 품종·규격·사진·재고·가격 | **에어테이블** 국내/판매 라인업 | 즉시 |
| 견적 요청 확인·상태 관리 | **에어테이블** 견적 관리 인터페이스 | 즉시 |
| 농장 재고 조정 | **open-garden.co.kr/stock.html** | 즉시 |
| 홈·소개·FAQ 문구 | **GitHub** `src/*.html` | 1~2분 |
| 사진 | **GitHub** `public/assets/` | 1~2분 |
| 색·여백·글자 크기 | **GitHub** `public/assets/*.css` | 1~2분 |
| 납품 사례 추가 | **GitHub** `src/index.html` | 1~2분 |

에어테이블은 바로 반영되고, GitHub는 저장하면 **1~2분 뒤 자동으로 사이트에 올라갑니다.**
배포 버튼을 따로 누를 필요 없습니다.

## 1. 문구 고치기 (가장 자주 하실 일)

GitHub 웹에서 바로 됩니다. 프로그램 설치 불필요.

1. https://github.com/BYEONGJUN33/opengarden_web 접속
2. `src` 폴더 → 고칠 파일 선택
   - `index.html` — 홈
   - `about.html` — 소개 (회사 소개 · 소싱 지도 · 수입 과정)
   - `faq.html` — 자주 묻는 질문
   - `catalog.html` — 카탈로그 화면
3. 오른쪽 위 **연필 아이콘(Edit)** 클릭
4. `Ctrl + F`로 바꿀 문구를 찾아 고칩니다
5. 아래로 내려 **Commit changes** 클릭 → 1~2분 뒤 사이트 반영

### 고칠 때 지켜주실 것

```html
<h3>현지 농가에서 직접 고릅니다</h3>
   └ 꺾쇠 < > 사이는 건드리지 마시고, 그 바깥 글자만 고치세요
```

- `<h3>` `</h3>` 같은 꺾쇠 표시는 **지우지 마세요.** 글자만 바꾸시면 됩니다
- 큰따옴표 `"` 안의 영어(`class="fbody"` 등)도 건드리지 마세요
- 한글만 바꾸면 거의 안전합니다

### 실수했을 때

GitHub 첫 화면에서 **Commits** → 되돌리고 싶은 항목 클릭 → **Revert**.
사이트가 깨져도 1~2분이면 복구되니 겁내지 않으셔도 됩니다.

## 2. 사진 바꾸기

1. GitHub에서 `public/assets/` 폴더로 이동
2. **Add file → Upload files**
3. 사진을 끌어다 놓고 **Commit changes**

| 자리 | 파일 | 권장 규격 |
|---|---|---|
| 홈 맨 위 큰 사진 | `assets/hero.jpg` | 가로 1920px 이상, 3:2 |
| 홈·소개 회사 사진 | `assets/about.jpg` | 1280×853 (3:2) |
| 소개 — 해외 농장 전경 | `assets/photos/nursery-wide.jpg` | 가로 1600px, 3:2 |
| 소개 — 온실 화분 | `assets/photos/greenhouse-plants.jpg` | 〃 |
| 소개 — 항공 화물 | `assets/photos/cargo-loading.jpg` | 〃 |
| 소개 — 식물 점검 | `assets/photos/plant-inspection.jpg` | 〃 |
| 소개 — 묘목 취급 | `assets/photos/plant-care.jpg` | 〃 |
| 카톡 공유 미리보기 | `assets/og.jpg` | 1200×630 |

> **3:2 비율**을 지켜주시면 사진이 잘리지 않습니다. 다른 비율도 들어가긴 하지만 좌우나 위아래가 잘립니다.
> 같은 파일명으로 덮어쓰면 자리는 그대로 두고 사진만 바뀝니다.

### ⚠ 사진 출처 기록은 반드시 함께 고쳐주세요

현재 소개 페이지 사진 5장은 **Pexels 무료 사진**이고, 출처가 `docs/photo-credits.md`에
기록돼 있습니다. 사진을 바꾸시면 이 파일도 같이 고쳐주세요.
오픈가든이 직접 찍은 사진으로 바꾸신다면 해당 줄을 지우시면 됩니다.

> 지금 사진들은 오픈가든 시설·직원이 아니라 스톡 사진입니다.
> 실제 현장 사진으로 바꾸시는 게 신뢰에 가장 큰 도움이 됩니다.

## 3. 납품 사례 추가

`src/index.html`에서 `<article class="case">`를 찾아 통째로 복사해 바로 아래 붙이고,
회사명·현장명·설명·사진 경로만 바꾸면 됩니다.

```html
<article class="case">
  <a href="/docent/ipark.html">            ← 상세 페이지가 있으면 주소, 없으면 지우고 <div>로
    <div class="case-img"><img src="/docent/images/og-cover.jpg" alt="현장 사진" ...></div>
    <div class="case-body">
      <div class="case-client">HDC 아이파크</div>         ← 회사명
      <h3>아이파크 언베일가든</h3>                         ← 현장명
      <p class="case-meta">2026 국제정원박람회 · -----</p>  ← 연도 · 역할
    </div>
  </a>
</article>
```

카드가 화면 폭을 넘길 만큼 쌓이면 **자동으로 옆으로 흐르기 시작합니다.** 설정할 것 없습니다.

## 4. 색·여백 바꾸기

디자인 값은 `public/assets/site.css`에 모여 있습니다. 맨 위 색 정의만 바꿔도 사이트 전체가 바뀝니다.

```css
--green: #1F4D33      /* 기본 초록 (버튼·강조) */
--green-dark: #123023 /* 진한 초록 (어두운 구간 배경) */
--ink: #111814        /* 본문 글자색 */
--bg-soft: #F4F6F3    /* 연한 배경 */
```

페이지별 세부 스타일은 `about.css`, `catalog.css`에 있습니다.

## 5. 절대 하시면 안 되는 것

| | 이유 |
|---|---|
| 에어테이블 **가격 필드를 사이트에 노출** | 도매가·단가_EUR·정가_KRW 등은 어떤 경로로도 브라우저에 가면 안 됩니다. `api/catalog.js`의 필드 목록이 유일한 관문입니다 |
| **에어테이블·솔라피 토큰을 코드·메신저에 붙여넣기** | 토큰은 Vercel 환경변수에만 둡니다. 한 번 노출되면 재발급해야 합니다 |
| `api/` 폴더 파일 수정 | 견적 접수·카탈로그가 멈출 수 있습니다 |
| `build.js` 수정 | 사이트 전체 빌드가 실패합니다 |

## 6. 더 큰 수정이 필요하면

문구·사진을 넘어서는 수정(레이아웃 변경, 새 페이지, 기능 추가)은
**Claude Code**에 말로 시키시는 게 가장 빠릅니다.

1. https://claude.ai/code 접속
2. 저장소 `BYEONGJUN33/opengarden_web` 선택
3. "소개 페이지 수입 과정 사진 바꿔줘" 처럼 평어로 요청

작업 내용은 전부 기록(커밋)으로 남아 언제든 되돌릴 수 있습니다.

## 7. 계정별 역할

| 서비스 | 용도 | 대표님께 필요한가 |
|---|---|---|
| **GitHub** | 코드·문구·사진 보관, 수정 이력 | **필수** — 이것만 있으면 수정은 전부 됩니다 |
| Vercel | 배포, 도메인, 환경변수(토큰) | 선택 — 로그 확인·롤백·도메인 변경 시에만 |
| 에어테이블 | 품종·재고·견적 데이터 | 필수 |
| 솔라피 | 견적 접수 알림톡 발송 | 선택 |

```
GitHub에 저장 → Vercel이 자동으로 받아 배포 → 1~2분 뒤 open-garden.co.kr 반영
```

이 흐름은 자동이라 신경 쓰지 않으셔도 됩니다.

> **참고:** Vercel 무료(Hobby) 플랜은 팀원 초대가 불가능하고 비상업적 용도로만 허용됩니다.
> 대표님을 Vercel에 초대하시려면 Pro 전환이 필요합니다(Viewer 좌석은 무료).
