# 오픈가든 에셋 — 생성형 AI(Gemini) 프롬프트

임시 플레이스홀더용. 실사진 확보 전까지 사용하고, 확정 실사진으로 교체할 것.
브랜드 톤: 딥 포레스트 그린(#1F4D33), 유럽 직수입 식물 B2B 공급, 신뢰감·전문성·자연광.

> 이미지 모델은 영어 프롬프트에서 품질이 가장 안정적입니다. 아래는 영어 프롬프트 + 한국어 요지.
> 각 프롬프트 끝의 `--ar`(비율)은 Gemini에서는 자연어로 이미 명시했으니 참고용입니다.

## 5. 로고 — ⚠️ 생성형 AI 비권장

- 로고는 텍스트·벡터 정합이 필요해 이미지 생성 AI가 깨진 글자를 내는 경우가 많음.
- 지금은 코드 내 임시 워드마크(`오픈<em>가든</em>`, 그린 강조)가 이미 동작 중 → **로고는 별도 처리** 권장
  (디자이너 의뢰 / 로고 전용 툴 / 심볼만 AI로 뽑고 글자는 폰트로 조합).
- 굳이 AI로 심볼 아이디어만 뽑을 경우:
```
A minimal flat vector logo symbol for a premium plant supply company named "OpenGarden",
a simple leaf or sprout combined with a subtle garden gate or open arch motif,
single deep forest green color (#1F4D33) on white, clean geometric, no text,
no gradient, scalable icon style, centered.
```
요지: 심볼만. 글자는 넣지 말 것(AI가 오타 냄). 단색 그린, 미니멀 플랫 벡터.

## 공통 주의사항

1. **글자·로고 넣지 말 것** — 모델이 항상 오타/깨진 글자를 냄. 모든 프롬프트에 `no text, no logos` 포함됨.
2. **사람 최소화** — 얼굴 클로즈업은 부자연스러운 결과가 잦음. `no people` 또는 `distant unidentifiable people`.
3. **4장 세트(사례·서비스)는 한 세션에서 연속 생성** — 톤/계절감 통일이 쉬움.
4. **저작권 메모**: 체크리스트 원칙은 "직접 촬영/사용권 있는 사진만, 스톡·타사 ❌".
   AI 생성물은 임시 플레이스홀더로만 쓰고, 확정 단계에서 실사진으로 교체 권장.
5. 원본 그대로(큰 사이즈) 받으면 리사이즈·크롭은 이쪽에서 처리.
