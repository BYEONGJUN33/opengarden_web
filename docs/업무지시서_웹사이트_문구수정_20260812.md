## 0. 작업 배경 (반드시 읽을 것)

기존 문구는 **"네덜란드 직수입상"** 포지션이었으나, 실제 사업은 국내 농가 매칭 + 해외 직소싱을 함께 하는 **"조달 창구"**임.
- 원산지(어디서 왔는지)를 앞세우지 말 것
- 고객의 일이 얼마나 줄어드는지를 앞세울 것
- Hoogenraad 공식 에이전시는 자랑이 아니라 "소싱 능력의 증거"로만, 소개 섹션 본문에서 1회 언급

## 0-1. 전역 금지어 (전 페이지 일괄 치환)

| 금지어 | 대체어 |
|---|---|
| 상담 | 견적 |
| 문의 | 요청 / 견적 요청 |
| 최저가 보장, 국내 유일 | 사용 금지 |

- `카카오톡 상담` → **`카카오톡 채널로 견적 받기`** (헤더·CTA·푸터 전부)
- 섹션 라벨 `서비스 문의` → **`견적 요청`**
- ⚠️ 카톡 채널 링크(`https://pf.kakao.com/_lGfxhX/chat`)는 그대로 유지, 문구만 교체

## 2. 지표 4칸 (숫자 스트립)

| 라벨 | 값 |
|---|---|
| 조달 경로 | 국내 농가 + 해외 직수입 |
| 소싱 네트워크 | 국내 전국 · 해외 4개국 |

- 값 텍스트가 길어져 1칸 2줄 될 수 있음 → 폰트 사이즈 하향 조정 허용

## 4. 소개 섹션

- 섹션 라벨: `오픈가든` (유지)
- 제목: **한 곳에 말하면, 나머지는 저희가 움직입니다.**
- 본문 1문단:
  > 현장에 필요한 식물이 한 농장에 다 있는 경우는 거의 없습니다. 오픈가든은 전국 거래 농가와 네덜란드·이탈리아·스페인·북미의 현지 농장을 함께 운용해, 국내에 있는 품목은 바로 매칭하고 없는 품목은 직접 들여옵니다. 유럽 최대 관목 생산자 Hoogenraad의 공식 한국 에이전시이자, 라이선스 품종(PBR) 도입 계약을 진행 중입니다.
- 본문 2문단:
  > 들여온 뒤가 더 중요합니다. 수입 품종은 자체 농장에서 우리 기후에 적응시킨 뒤 출하하고, 수입 원가 구조는 그대로 공개합니다. 목록에 없는 품종도 말씀만 주세요.
- 링크 텍스트: `거래 네트워크 · 수입 과정 보기` (유지)
- 이미지 `assets/about.jpg` alt: `국내 순화 중인 수입 묘목 — 오픈가든 자체 농장`으로 수정

| 1 | 품목 요청 | 카탈로그에서 담거나 필요한 품종·규격을 남기면 접수 완료 |
| 2 | 조달 경로 확인 | 국내 재고와 해외 소싱 가능 여부를 확인해 견적·제안서로 회신 |
