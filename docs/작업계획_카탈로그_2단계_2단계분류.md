## 설계

### 2-1. 상태
```js
let cat = "전체";   // 1단 (기존)
let sub = "전체";   // 2단 (신규)
```
- 1단을 바꾸면 `sub`는 항상 `"전체"`로 초기화
- 필터는 AND: `groupOf(p)===cat && subOf(p)===sub`

### 2-2. 2단 키 — 정규화로 표기 흔들림 흡수
```js
// '조팝' / '조팝나무' → 같은 칩. 공백 제거 + 끝의 '나무' 제거
const subKey = (s) => String(s||'').replace(/\s+/g,'').replace(/나무$/,'');
```
표시 라벨은 **데이터에 실제로 나타난 변형 중 가장 긴 것**을 씁니다.
(`조팝` / `조팝나무` 둘 다 있으면 `조팝나무`로 표시 — 조경 현장 표기에 가까움)

`산수국`·`목수국`·`수국`은 정규화해도 서로 다른 키라 합쳐지지 않습니다. 의도한 동작입니다.

카테고리 값이 비어 있으면 학명의 라틴 속명으로 대체하고, 그것도 없으면 2단에서 제외합니다.

### 2-3. UI
- 1단 아래에 `.subchips` 한 줄 추가. `cat==="전체"`이거나 하위가 1개 이하면 미표시
- 스타일은 기존 `.chip` 재사용하되 약간 작게(높이 −4px, 연한 배경)
- 각 칩에 건수 표시 — 기존 1단과 동일한 방식
- 모바일 가로 스크롤 (기존 `.chips`와 동일 처리)
- 1단 전환 시 2단 줄이 갑자기 나타나며 그리드가 밀리므로, 줄 높이를 **미리 확보**해
  레이아웃 점프를 막습니다

### 2-4. 접근성
- `.subchips`에 `role="group"` + `aria-label="세부 분류"`
- 선택된 칩에 `aria-pressed="true"`
- 1단 변경 시 2단 줄에 `aria-live="polite"`로 변경 사실 전달

### 2-5. 건드리지 않는 것
- `groupOf()` 로직, 라틴 속명 매핑, 에어테이블 예외표 — 그대로
- 검색·내한성·공급구분 필터 — 그대로 (AND 유지)
- 견적 담기·localStorage — 무관
