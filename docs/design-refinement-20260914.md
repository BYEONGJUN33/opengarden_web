# 디자인 정리 및 휴대폰 시연

## 접근 및 구조 확인

- GitHub 연결로 비공개 저장소의 루트 파일 목록과 README를 읽고 읽기·쓰기 권한 확인.
- 기준 커밋: `0347724` (main), 작업 브랜치: `codex/design-refinement-phone-demo`.
- 실제 페이지 원본은 `src/`의 index, about, catalog, faq, privacy 5개 HTML.
- `partials/`는 공통 헤더·모바일 메뉴, 푸터, 카카오 버튼을 보관.
- `build.js`는 공통 블록을 치환하고 `public/` 자산과 함께 `dist/` 생성. 빌드 후 헤더 일치 검사.
- `public/docent/ipark.html`과 `public/stock.html`은 독립 정적 페이지.
- `api/catalog.js`, `api/stock.js`는 조회, `api/quote.js`는 견적 접수 담당.
- README와 일부 기존 설계 문서의 public 원본/2페이지 설명은 현재 구현보다 오래된 정보.

## 변경

- `public/assets/site.css`: 5개 페이지가 공유하는 시각 스타일. 기존 색상 변수와 글꼴 유지.
- 지표·서비스는 구분선 중심, 사진·카탈로그 카드는 작은 모서리, 부유 그림자와 호버 이동 축소.
- 제목·본문·보조 설명 크기, 행간, 간격 조정. 서브페이지 제목 정렬과 홈 이동 경로 통일.
- 카탈로그 안내를 실제 연락처 접수 방식에 맞게 수정. API와 견적 로직은 변경하지 않음.
- 홈 사례를 넓은 사진과 설명으로 배치. 역할이 확정되지 않은 자리표시자 대신 정원 도슨트 연결 표시.
- 홈 `#demo`: 실제 아이파크 도슨트를 휴대폰 프레임에서 열기, 내부 스크롤·분류 펼치기, 초기화, 별도 창 열기.
- 시연은 시작 버튼을 누른 후에만 기존 도슨트를 로드하며 데이터 복제나 자동 접수 없음.
- 공통 메뉴에 정원 시연 링크 추가. 320px 헤더 줄바꿈 및 숨긴 모바일 메뉴 노출 개선.
- 루트릭스(https://www.rootrix.com/)는 휴대폰 화면과 설명의 병렬 구성만 참고. 이미지·카피·수치 복제 없음.

## 검증

- `npm run build`: 5페이지 빌드 및 헤더 일치 통과.
- `node --check public/assets/phone-demo.js`, `git diff --check` 통과.
- 브라우저 320px에서 5개 페이지의 문서 가로 넘침 없음. 390px 모바일, 1440px 데스크톱 시각 검수.
- 샘플 카탈로그 검색 → 1건 → 담기 → 1종 표시 → 견적 모달 확인.
- FAQ 분류 필터 및 답변 펼치기, 모바일 메뉴 열기 확인.
- 시연 시작·초기화 및 내부 New Plants 분류 펼치기 확인.
- 실데이터 환경변수 없이 검수. 실제 견적 전송·운영 배포·main 병합은 수행하지 않음.

## 로컬 확인

`npm run dev` 실행 후 홈 메뉴의 ‘정원 시연’ 선택. 다른 서버와 포트가 겹치면 PORT 환경변수 지정.
공통 스타일 수정은 `public/assets/site.css`, 시연 구성은 `src/index.html`, 시연 동작은 `public/assets/phone-demo.js`에서 관리.
